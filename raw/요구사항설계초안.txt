## 1. 전체 구조

**형태**: 단일 웹 페이지 앱 (HTML/CSS/JS 한 파일) — 브라우저에서 바로 작동, 설치 불필요
**주요 화면 4개**:
- 단어 목록 관리 (엑셀 업로드/추가/교체)
- 레벨 선택 화면
- 레벨1/2/3 학습 화면 (공통 레이아웃, 모드만 다름)
- 결과/진행 요약 화면

## 2. 단어 데이터 관리 (엑셀 업로드)

- 엑셀 파싱은 SheetJS(xlsx) 라이브러리 사용
- 필요한 컬럼: **단어(word)**, **뜻(meaning)** — 발음기호는 선택
- 업로드 시 두 가지 옵션 제공: **교체(replace)** / **추가(add)**
- 파싱된 단어 목록은 브라우저에 저장해서 다음 방문 시에도 유지

**확인이 필요한 점**: 엑셀 컬럼명/순서를 고정할까요, 아니면 첫 줄(헤더)을 보고 자동으로 "단어/뜻" 컬럼을 찾게 할까요?

## 3. 발음(음성) 처리

브라우저 내장 음성합성(Web Speech API, `speechSynthesis`)을 사용하는 방법을 추천합니다.
- 장점: 별도 음원 파일이나 API 키 없이 바로 작동, 무료
- 단점: 발음 품질이 실제 원어민 녹음보다는 약간 기계적임

**확인이 필요한 점**: 이 정도 품질이면 충분한가요, 아니면 나중에 직접 녹음한 mp3 파일을 단어별로 매칭하는 방식으로 확장하고 싶으신가요?

## 4. 레벨별 동작 설계

**레벨 1 (보기+듣기+뜻)**
- 단어 카드 표시 → 자동 재생 → 뜻 표시, 약 5초 후 다음 단어로 자동 전환
- 일시정지/이전·다음 버튼 정도만 추가

**레벨 2 (카드 배열)**
- 발음 재생 → 정답 스펠링의 알파벳을 무작위로 섞은 카드 제시
- 카드를 클릭(또는 드래그)해서 순서대로 배치 → 빈 슬롯에 채워지는 방식
- 정답 확인 시 즉시 피드백(정답/오답 표시), 오답 시 재도전 가능

**레벨 3 (키보드 입력)**
- 발음 재생 → 텍스트 입력창에 스펠링 입력 → Enter 또는 확인 버튼으로 채점
- 오답 시 정답 표시 후 다음 단어

**공통 요소**: 다시 듣기 버튼, 진행률 표시(예: 5/20), 정답률 집계

## 5. 데이터 저장

- 단어 목록, 학습 진행 상황, 레벨별 정답률 등은 브라우저 저장소에 보관
- 기기/브라우저를 바꾸면 초기화되는 점은 감안 필요 (필요하면 나중에 내보내기/불러오기 기능 추가 가능)

## 6. 제작 순서 (실제 빌드 시)

1. 정적 UI 뼈대 (레벨 선택 + 3개 학습 화면)
2. 엑셀 업로드 → 파싱 → 단어 목록 렌더링
3. 레벨1 (가장 단순) 구현 → 음성 재생 확인
4. 레벨3 (입력 채점) 구현
5. 레벨2 (카드 배열, 가장 복잡한 UI) 구현
6. 진행률/정답률 저장 및 통계 화면 추가
