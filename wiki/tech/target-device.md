# 대상 기기 — 갤럭시 탭 S7+

사용자 답변(2026-09-26): 아이는 **갤럭시 탭 S7+** 를 쓴다. → [Q-12](../open-questions.md#q-12)

## 사양 (일반 공개 사양 기준, 실제 기기에서 확인 필요)
| 항목 | 값 | 앱에 주는 영향 |
|---|---|---|
| 화면 | 12.4인치, 2800×1752, 120Hz | 태블릿 레이아웃. 카드와 버튼을 크게, 가로 모드 우선 |
| OS | Android 10 출시 → 최대 Android 13 (One UI 5) 업데이트 | minSdk 26이면 충분. targetSdk는 최신 사용 |
| 기본 키보드 | 삼성 키보드 | [ADR 0004](../decisions/0004-system-keyboard.md): 삼성 키보드의 예측 입력이 꺼지는지 반드시 확인 |
| TTS | 삼성 TTS 또는 Google TTS | 영어(미국) 음성 데이터 설치 여부 확인 |
| 연결 | USB-C | 개발 중 USB 디버깅으로 설치 |

## 레이아웃 방침 (제안)
- **가로 모드 우선**, 세로 모드도 깨지지 않게 한다.
- 레벨 3(쓰기): 가로 모드에서 키보드가 화면 아래 절반 가까이를 차지한다. 단어·버튼 영역은 위쪽 절반 안에 들어가게 한다.
- 터치 영역은 최소 64dp 이상 (초1 기준, 일반 권장값 48dp보다 크게)

## 개발 중 연결 (USB 디버깅)
1. 설정 → 태블릿 정보 → 소프트웨어 정보 → **빌드 번호 7번 탭** → 개발자 모드 켜짐
2. 설정 → 개발자 옵션 → **USB 디버깅** 켜기
3. USB로 PC에 연결 → 태블릿에 뜨는 "USB 디버깅 허용"에서 **허용**

## 두 번째 기기 — 갤럭시 Z 폴드7 (2026-09-27 추가)
사용자 요청으로 설치했다. 모델 SM-F966N, Android 17(SDK 37), 기본 키보드는 삼성 키보드, 기본 TTS는 삼성 TTS(`com.samsung.SMT`).

| 화면 | 해상도 | 폭(dp, 420dpi) | 앱 배치 |
|---|---|---|---|
| 바깥 화면(접었을 때) | 1080×2520 | 약 411dp | **좁은 화면 배치**(`isCompactWidth()`, 600dp 미만) |
| 안쪽 화면(펼쳤을 때) | 1968×2184 | 약 750dp | 태블릿과 같은 배치 |

- 학습 기록은 기기마다 따로 저장된다(태블릿 기록은 옮겨지지 않음). 폴드7에는 태블릿에서 가져온 단어 DB(학습 기록 제외)를 넣었다.
- adb: 화면이 두 개라 `screencap -d <SurfaceFlinger display id>`로 캡처해야 한다(바깥 4630946872173396372, 안쪽 4630946449689556883).
- 안쪽 화면 점검은 폰을 펼치지 않고 `wm size 1968x2184`로 흉내 냈고, 점검 후 `wm size reset`으로 되돌렸다.

### 점검 결과와 조치 (2026-09-27)
| 화면 | 문제 | 조치 |
|---|---|---|
| 바깥·레벨 2 카드 | 5글자에서도 빈칸이 화면 밖으로 넘침(칸 84dp 고정) | 빈칸 크기를 폭에 맞춰 줄임(최대 84dp). 안쪽 화면의 8글자 이상 단어도 해결 |
| 바깥·레벨 1 듣기 | zookeeper가 두 줄로 나뉨, "다음 ▶" 버튼이 화면 밖 | 단어 글자 크기를 폭에 맞춤, 버튼을 FlowRow로 줄바꿈 |
| 바깥·레벨 선택 | 카드 3개가 좁아서 설명 글자가 잘림 | 좁은 화면에서는 세로로 쌓은 가로형 카드 |
| 바깥·홈 | 한 줄에 카드 하나, 스크롤이 많음 | 레슨 2열, 🏆·🔁 카드는 전체 폭 |
| 바깥·레벨 3 쓰기 | 입력칸이 좁아 긴 단어가 옆으로 밀림 | 입력칸을 전체 폭으로, 확인 버튼은 아래에 두고 글자 34sp |
| 바깥·제목 줄 | "레슨 3"이 두 줄로 넘어감 | 좁은 화면에서는 "←"만 표시하고 제목은 한 줄 말줄임 |
| 바깥·대회 시작, 결과, 부모 설정 | 가로 배치가 비좁음 | 세로로 쌓음(결과 화면은 스크롤) |
| 안쪽 | 홈 2열, 듣기 버튼 4개가 모두 보이는 등 대체로 정상 | 카드 빈칸 문제만 위 조치로 해결 |
