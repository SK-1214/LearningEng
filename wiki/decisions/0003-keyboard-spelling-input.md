# ADR 0003: 철자는 아이가 키보드로 직접 입력

- **결정일**: 2026-09-26 (사용자 답변)
- **관련 질문**: [Q-9](../open-questions.md#q-9) (일부 해결)

## 결정
철자 연습의 핵심 방식은 **아이가 키보드로 직접 입력**하는 것이다. 말로 철자를 대거나 손으로 쓰는 방식은 지원하지 않는다.

## 영향
- **레벨 3 쓰기**가 가장 중요한 레벨이다. 개발 순서에서도 레벨 1 듣기 다음으로 먼저 만든다. → [학습 레벨](../learning/learning-levels.md)
- 음성 인식, 필기 인식 기능은 범위에서 뺀다.
- 알파벳을 하나씩 읽어 주는 "철자 듣기" 제안은 우선순위를 낮춘다.
- 키보드 종류: 안드로이드 기본 키보드로 결정 → [ADR 0004](0004-system-keyboard.md)
