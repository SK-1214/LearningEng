# 미결정 사항

결정되면 `decisions/`에 ADR을 만들고 여기에는 ✅ 표시와 링크를 남긴다.

### Q-1
✅ **해결 (2026-09-26)** → [ADR 0001](decisions/0001-native-android.md): 네이티브(Kotlin + Jetpack Compose)로 개발.
- 원래 질문: 원본 초안은 단일 웹 페이지 앱인데 목표는 안드로이드 앱이었다. 네이티브로 만들지, 웹앱을 WebView/PWA로 감쌀지.

### Q-2
엑셀 컬럼명·순서를 고정할지, 헤더를 자동 인식할지. → [단어 데이터](product/word-data.md)
- 업데이트(2026-09-26): 실제 파일의 헤더는 `Lesson | word | meaning`. 제안: 헤더 이름으로 찾기(한글 헤더 허용), `Lesson` 열은 선택 항목.

### Q-3
TTS 품질로 충분한지, 녹음 파일을 쓸지. → [발음·TTS](tech/pronunciation-tts.md)

### Q-4
"추가" 업로드 때 중복 단어 처리 방식 (무시 / 뜻 덮어쓰기 / 둘 다 유지).
- 업데이트(2026-09-26): 실제 엑셀에서 `buy`, `run`, `together`가 서로 다른 레슨에 중복으로 나온다. 제안: 레슨별 목록은 그대로 두고 학습 기록은 단어 단위로 합친다 → [데이터 모델](tech/storage.md#데이터-모델-초안-제안). "교체" 때 학습 기록을 유지할지도 정해야 한다.

### Q-5
부모용 관리 화면을 잠글지, 잠근다면 방식은 무엇인지 (간단한 산수 문제, PIN 등).

### Q-6
보상 요소(별, 스티커, 연속 학습일)를 넣을지.

### Q-7
오답 복습, 간격 반복(SRS)을 넣을지, 넣는다면 언제 넣을지.
- ✅ 오답 복습 (2026-09-26, 사용자 요청): 레슨 목록에 "틀린 단어" 모음을 추가했다 → [틀린 단어 모음](learning/learning-levels.md#틀린-단어-모음-오답-다시-테스트)
- 남은 질문: 맞힌 단어도 며칠 뒤 다시 묻는 간격 반복(SRS)을 넣을지

### Q-8
**단어 데이터 오류 의심**: 9-3 `line`의 뜻이 "선글라스"로 되어 있다(8-4 `sunglasses`에서 복사된 것으로 보임). → [단어 리스트 요약](sources/wordlist-spelling-bee.md)
- ✅ **해결 (2026-09-26)**: 사용자가 raw 엑셀을 고쳤다. 9-3 `line` = **"줄, 선"**. 다시 읽어서 확인했고, 다른 행은 바뀌지 않았다.

### Q-9
**스펠링 비 대회 형식과 일정**
- ✅ 입력 방식 해결 (2026-09-26) → [ADR 0003](decisions/0003-keyboard-spelling-input.md): 아이가 **키보드로 직접 입력**한다.
- ✅ 일정 (2026-09-26): 첫 대회는 **2026년 10월 중순**이고, 이후에도 대회가 계속 있어 **앱을 계속 쓸 예정**이다. → [MVP 로드맵](product/mvp-roadmap.md#일정)
- 남은 질문: 대회에서 뜻이나 예문을 들려주는지. → [학습 레벨](learning/learning-levels.md)

### Q-10
레슨 1~3이 없다(엑셀은 레슨 4~12). 이미 끝난 레슨인지, 나중에 추가될 예정인지?
- 업데이트(2026-09-27): 사용자가 **레슨 3을 추가**했다(10단어). 레슨 1~2는 아직 없다. 새 레슨이 계속 추가될 수 있으므로, 앱은 엑셀에 있는 레슨을 그대로 보여 준다.
- 참고: 엑셀 `Lesson` = 레슨(단어 묶음), 레벨 = 듣기/카드/쓰기 → [ADR 0005](decisions/0005-lesson-and-level-terms.md)

### Q-12
✅ **해결 (2026-09-26)**: **갤럭시 탭 S7+** (12.4인치, 2800×1752, 기본 키보드는 삼성 키보드, 최대 Android 13 / One UI 5). → [대상 기기](tech/target-device.md)
- 원래 질문: 폰인지 태블릿인지, 안드로이드 버전(또는 모델명)은 무엇인지.

### Q-11
✅ **해결 (2026-09-26)** → [ADR 0004](decisions/0004-system-keyboard.md): 안드로이드 기본 키보드를 쓴다.
- 원래 질문: 앱 전용 큰 알파벳 키보드 vs 안드로이드 기본 키보드(자동완성·자동수정 끔). 대회가 태블릿이나 PC 키보드로 진행된다면 기본 키보드 연습이 실전에 가깝다. → [학습 레벨](learning/learning-levels.md)
