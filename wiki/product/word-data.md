# 단어 데이터 (엑셀 업로드)

## 원본 초안 내용 (출처: raw/요구사항설계초안.txt)
- 필수 컬럼: **단어(word)**, **뜻(meaning)**. 발음기호는 선택.
- 업로드 옵션: **교체(replace)** / **추가(add)**
- 파싱한 목록은 기기에 저장해 다음 실행에도 유지.
- 초안의 SheetJS는 웹용 → 안드로이드는 [엑셀 파싱 후보](../tech/android-stack.md#엑셀-파싱) 참고

## 실제 엑셀 형식 (출처: raw/wordlists/spelling bee contest.xlsx)
상세 내용: [단어 리스트 요약](../sources/wordlist-spelling-bee.md)

| 열 | 헤더 | 예 | 비고 |
|---|---|---|---|
| A | `Lesson` | `4-1` | "레슨-순번" 문자열. **Lesson = 레슨** ([ADR 0005](../decisions/0005-lesson-and-level-terms.md)). 초안에는 없던 열 |
| B | `word` | `take off` | 소문자. 띄어쓰기 포함 가능 |
| C | `meaning` | `조금, 약간의` | 한국어. `~`, 쉼표 포함 가능 |

- 2026-09-27 기준: 레슨 3~12, 레슨당 10단어, 총 100행 (고유 단어 96개). 새 레슨은 시트 아래에 추가되어도 번호순으로 정렬된다(레슨 3은 92~101행)

## 이 파일에서 드러난 요구사항
1. **레슨 단위 학습**: `Lesson` 열 기준으로 "레슨 선택 → 레벨 선택" 흐름을 쓴다. 제안: 레슨 여러 개를 골라 섞어 학습하는 기능.
2. **중복 단어**: `buy`, `run`, `together`가 서로 다른 레슨에 한 번씩 더 나온다. 레슨별 목록은 그대로 두되, **학습 기록(정답률)은 단어 단위로 합치는 것**을 제안한다. → [Q-4](../open-questions.md#q-4)
3. **띄어쓰기 단어**: `take off`, `movie star` → 레벨 2(카드)와 레벨 3(쓰기)에서 공백 처리가 필요하다. → [학습 레벨](../learning/learning-levels.md)
4. **데이터 오류 가능성**: 9-3 `line`=선글라스(지금은 수정됨)처럼 부모가 올린 엑셀에 오류가 있을 수 있다. 제안: 업로드 후 미리보기, 앱 안에서 뜻 수정 기능. → [Q-8](../open-questions.md#q-8)

## 파싱 규칙 (제안)
- 첫 행을 헤더로 보고 `Lesson` / `word` / `meaning`을 이름으로 찾는다. 대소문자와 앞뒤 공백은 무시하고, `Level` 및 한글 헤더(`레슨`, `레벨`, `단어`, `뜻`)도 허용한다. → [Q-2](../open-questions.md#q-2)
- `Lesson` 열이 없으면 전체를 레슨 하나로 취급한다.
- `word`는 앞뒤 공백을 제거하고 소문자로 바꾸며, 중간 공백은 하나로 줄인다.
- `word`나 `meaning`이 빈 행은 건너뛰고 몇 행을 건너뛰었는지 알려준다.
- `Lesson` 값 `4-1`은 레슨 `4`와 순번 `1`로 나누되, 형식이 다르면 문자열 그대로 레슨 이름으로 쓴다.
- 주의: 엑셀이 `4-1`을 날짜로 바꿔 버리는 경우가 있으므로 날짜형 셀도 처리해야 한다.
