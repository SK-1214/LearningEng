# 첫 버전(MVP) 범위와 개발 순서

**목표**: 아이가 엑셀의 모든 레슨(2026-09-27 기준 레슨 3~12, 100행) 단어를 **듣고, 키보드로 철자를 입력하며** 스펠링 비 대회를 연습할 수 있는 가장 작은 앱.

근거: [ADR 0001 네이티브](../decisions/0001-native-android.md) · [ADR 0005 용어](../decisions/0005-lesson-and-level-terms.md) · [ADR 0003 키보드 입력](../decisions/0003-keyboard-spelling-input.md) · [ADR 0004 기본 키보드](../decisions/0004-system-keyboard.md)

## 순서를 정한 원칙
1. **데이터 먼저**: 단어를 읽지 못하면 다른 기능을 확인할 수 없다.
2. **대회에 가장 중요한 것 먼저**: 레벨 3 쓰기가 핵심이다(ADR 0003). 레벨 2 카드는 쓰기 다음으로 미룬다.
3. **각 단계가 끝나면 실제로 써 볼 수 있는 앱**이어야 한다. 아이에게 일찍 보여 주고 반응을 반영한다.
   - 초안의 순서(듣기 → 쓰기 → 카드)와 같다.

## 범위

### 포함 (MVP)
| 기능 | 비고 |
|---|---|
| 엑셀 가져오기 — **교체**만 | 헤더 자동 인식, 미리보기 후 확정 |
| 레슨 선택 → 레벨 선택 | 엑셀의 레슨(현재 3~12), 레슨별 진행률 |
| 레벨 1 듣기 | TTS, 자동 넘김, 일시정지/이전/다음 |
| **레벨 3 쓰기** | 기본 키보드, 자동완성 끄기, 채점, 틀린 단어 다시 풀기 |
| 레벨 2 카드 | 탭으로 배치, 같은 글자는 서로 바꿔도 정답 |
| 결과 화면 | 정답률, 틀린 단어 목록, 별(간단한 보상) |
| **틀린 단어 모음** (사용자 요청) | 레슨 목록 맨 앞의 가상 레슨. 레벨 3에서 마지막으로 틀린 단어를 모든 레슨에서 모아 다시 테스트 |
| 학습 기록 저장 | Room, 단어 기준으로 합침 |

## 개발 단계

### M0. 프로젝트 준비
- Android Studio 프로젝트: Kotlin, Jetpack Compose, Navigation Compose, Room
- minSdk 26, 대상 기기는 갤럭시 탭 S7+ (Android 13) → [대상 기기](../tech/target-device.md)
- 개발용으로 `spelling bee contest.xlsx`를 테스트 리소스에 복사한다(raw 원본은 그대로 둔다).
- git 저장소 초기화
- **완료 기준**: 빈 화면 앱이 실제 기기에서 실행된다.

### M1. 단어 데이터 — 엑셀 가져오기
- xlsx 직접 파서 (`ZipInputStream` + `XmlPullParser`) → [기술 스택](../tech/android-stack.md#엑셀-파싱)
- 파싱 규칙 → [단어 데이터](word-data.md#파싱-규칙-제안)
- Room 스키마 `Word` / `Level` / `LevelWord` / `Attempt` → [데이터 저장](../tech/storage.md)
- 부모 화면: 파일 선택(SAF) → 미리보기(레슨별 개수, 건너뛴 행) → 교체 확정
- **단위 테스트**: 실제 파일 → 90행, 레슨 9개, 고유 단어 87개, `take off`·`movie star` 공백 유지, 9-3 `line`=`줄, 선`
- **완료 기준**: 엑셀을 가져오면 앱 안에서 레슨별 단어 목록을 볼 수 있다.

### M2. 레슨·레벨 선택 + TTS + 레벨 1 듣기
- 레슨 선택 화면(레슨별 큰 카드) → 레벨 선택(👀 1 듣기 · 🧩 2 카드 · ⌨️ 3 쓰기, 아직 만들지 않은 레벨은 비활성)
- TTS 초기화: 영어 음성 데이터가 없으면 설치 안내, 속도 0.8
- 레벨 1 듣기: 단어 → 발음 → 뜻 → 자동 넘김, 일시정지/이전/다음/다시 듣기
- 전체 단어를 TTS로 재생해 보고 이상한 발음(`read`, `wind` 등)을 기록 → [발음·TTS](../tech/pronunciation-tts.md)
- **완료 기준**: 아이가 레슨을 골라 단어를 보고 들을 수 있다. → **아이에게 처음 보여주기**

### M3. 레벨 3 쓰기 ⭐ 핵심
- 발음 재생 → `TextField` 입력 → 완료 키로 채점
- [ADR 0004](../decisions/0004-system-keyboard.md) 체크리스트: 자동완성·자동수정·추천 끄기, 영문·공백만 입력, 한글 입력 시 안내, `imePadding`
- 채점: 대소문자·앞뒤 공백 무시, 연속 공백은 하나로 봄
- 오답이면 정답 표시 → 다음 단어. `Attempt` 기록
- 결과 화면: 정답률, 틀린 단어, 별, "틀린 단어 다시 하기"
- **실기기 테스트**: Gboard와 삼성 키보드에서 추천 단어가 뜨지 않는지 확인
- **완료 기준**: 레슨 하나를 레벨 3 쓰기로 끝까지 풀고 결과를 볼 수 있다. → **대회 연습이 가능한 첫 버전**

### M4. 레벨 2 카드
- 섞인 글자 카드를 탭하면 다음 빈칸에 들어간다. 빈칸을 탭하면 카드를 되돌린다.
- 글자로 비교해 채점(같은 글자 카드는 서로 바꿔도 정답), 공백 칸은 미리 고정
- 8글자 이상이면 첫 글자를 힌트로 채워 둔다.
- **완료 기준**: 모든 단어를 레벨 2 카드로 풀 수 있다(10글자 단어 포함).

### M5. 진행률과 다듬기
- 레슨 선택 화면에 레슨별 진행률·별 표시
- ✅ "전체 대회 연습": 모든 레슨을 섞고 뜻을 숨긴 레벨 3 쓰기(10·20·전체 선택, 💡 뜻 보기) — 2026-09-27 구현
- 큰 글씨·버튼 점검, 정답/오답 효과음과 애니메이션
- 기기에 APK를 직접 설치해 배포(플레이스토어는 쓰지 않음)
- **완료 기준**: 아이가 부모 도움 없이 레슨과 레벨을 골라 학습을 끝낼 수 있다.

## 일정
사용자 답변(2026-09-26): 첫 대회는 **10월 중순**이고, 이후에도 대회가 계속 있어 앱을 오래 쓴다. → [Q-9](../open-questions.md#q-9)

| 목표 | 시점 | 내용 |
|---|---|---|
| 1차 | **~10월 초** | M0~M3 완료 → 대회 전 1~2주 동안 레벨 3 쓰기로 연습 |
| 2차 | 첫 대회 이후 | M4(카드), M5(다듬기) |
| 이후 | 계속 | 제외했던 기능: 추가 업로드(새 단어 목록), SRS 복습, 보상 확장 |

- 계속 쓰는 앱이므로 **새 대회 단어 목록을 올려도 학습 기록이 유지되는 구조**(단어 기준 기록, [데이터 저장](../tech/storage.md))를 처음부터 지킨다.
- 대상 기기: [갤럭시 탭 S7+](../tech/target-device.md) → 가로 모드 우선 태블릿 레이아웃

## 개발 환경
PC에 Android Studio가 없으므로 **명령줄 도구로 빌드**한다(사용자 PC, 2026-09-26 설정).
- JDK 17, Android SDK command-line tools, Gradle → `C:\Users\sk80l\dev\`
- 빌드: `gradlew assembleDebug` → USB로 연결한 태블릿에 `adb install`
- 코드 위치: 프로젝트 루트의 `android/` 폴더
- 빌드 명령 (Git Bash):
  ```
  cd android && JAVA_HOME='C:\Users\sk80l\dev\jdk-17' ./gradlew testDebugUnitTest assembleDebug
  C:/Users/sk80l/dev/android-sdk/platform-tools/adb.exe install -r app/build/outputs/apk/debug/app-debug.apk
  ```
