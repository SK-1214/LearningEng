# 화면 구성

용어는 [ADR 0005](../decisions/0005-lesson-and-level-terms.md)를 따른다. **레슨** = 엑셀 `Lesson`(현재 3~12), **레벨** = 레벨 1 듣기 / 레벨 2 카드 / 레벨 3 쓰기.

앱 흐름: **레슨 선택 → 레벨 선택 → 학습 → 결과**

| # | 화면 | 사용자 | 내용 |
|---|---|---|---|
| 1 | 단어 목록 관리 | 부모 | 엑셀 업로드(교체/추가), 목록 확인 → [단어 데이터](word-data.md) |
| 2 | 레슨 선택 (홈) | 자녀 | 엑셀의 레슨(현재 3~12) 중 선택. 레슨마다 진행률(⭐ = 레벨 3에서 맞힌 단어 수) 표시. 맨 앞에 **🔁 틀린 단어** 카드(오답이 있을 때만) → [틀린 단어 모음](../learning/learning-levels.md#틀린-단어-모음-오답-다시-테스트) |
| 3 | 레벨 선택 | 자녀 | 레벨 1 듣기 / 레벨 2 카드 / 레벨 3 쓰기 → [학습 레벨](../learning/learning-levels.md) |
| 4 | 학습 화면 | 자녀 | 공통 레이아웃에 레벨별 동작만 다름 |
| 5 | 결과/진행 요약 | 자녀·부모 | 정답률, 진행률 |

- 원본 초안(raw/요구사항설계초안.txt)은 화면 4개(관리, 레벨 선택, 학습, 결과)였다. 실제 엑셀에 `Lesson` 열이 있어 레슨 선택 화면이 추가되었다.
- 홈 맨 앞 카드 순서: **🏆 대회 연습** → **🔁 틀린 단어**(있을 때만) → 레슨(번호순, 현재 3~12). 대회 연습은 문제 수 선택 화면(10·20·전체)을 거친다 → [대회 연습](../learning/learning-levels.md#대회-연습-m5)

## 공통 요소 (학습 화면)
- 다시 듣기 버튼
- 진행률 표시 (예: 5/20)
- 정답률 집계

## 제안 (초1 사용자 고려)
- 레벨 선택은 글자 대신 큰 그림 카드(👀 / 🧩 / ⌨️)로 보여준다. (구현됨)
- 제안: 결과 화면에 별·스티커 같은 보상을 둔다. [Q-6](../open-questions.md#q-6)
- 제안: 부모용 관리 화면(1번)은 잠금으로 분리한다. [Q-5](../open-questions.md#q-5)
