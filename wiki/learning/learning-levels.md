# 학습 레벨 설계

용어는 [ADR 0005](../decisions/0005-lesson-and-level-terms.md)를 따른다. **레슨**은 단어 묶음(엑셀 `Lesson`, 현재 3~12)이고, **레벨**은 공부하는 단계(듣기/카드/쓰기)다. 원본 초안의 "레벨 1/2/3"과 같은 뜻이다.

앱 흐름: **레슨 선택 → 레벨 선택 → 학습**

난이도 순서: 인지(보고 듣기) → 재인·조합(카드 배열) → 회상(직접 입력).

| 레벨 | 이름 | 아이콘 | 핵심 | 코드 (`StudyMode`) |
|---|---|---|---|---|
| 레벨 1 | 듣기 | 👀 | 보고, 듣고, 뜻 알기 | `LISTEN` |
| 레벨 2 | 카드 | 🧩 | 섞인 알파벳 카드 배열 | `CARD` |
| **레벨 3** | **쓰기** | ⌨️ | **키보드로 직접 입력 — 최우선** ([ADR 0003](../decisions/0003-keyboard-spelling-input.md)) | `TYPE` |

## 레벨 1 — 듣기
(출처: raw/요구사항설계초안.txt)
- 단어 카드 표시 → 발음 자동 재생 → 뜻 표시 → 약 5초 뒤 다음 단어로 자동 넘김
- 조작: 일시정지, 이전/다음
- 제안: 5초는 아이에 따라 빠를 수 있으므로 간격 조절 또는 탭하면 넘어가기를 둔다.
- 뜻은 엑셀 값을 그대로 보여준다. `sweet`=향기로운처럼 교재 문맥 뜻이 있으므로 사전 뜻으로 바꾸지 않는다.

## 레벨 2 — 카드
- 발음 재생 → 정답 스펠링의 알파벳을 섞은 카드 제시 → 빈 슬롯에 순서대로 채움
- 정답/오답 즉시 피드백, 오답이면 다시 도전
- 제안: 드래그보다 **탭하면 다음 빈칸에 들어가기**가 초1에게 쉽다. 틀린 카드를 누르면 흔들리는 효과 정도로 부드럽게 알린다.
- 긴 단어: 최대 10글자(`sunglasses`, `skateboard`, `basketball`). 제안: 8글자 이상이면 앞 몇 글자를 미리 채워 주는 힌트를 준다.
- 같은 글자가 반복되는 단어(`ball`, `too`, `groceries`)는 카드 ID가 아니라 **글자로 비교**해 채점한다.
- 띄어쓰기 단어(`take off`, `movie star`)는 공백 칸을 미리 고정해 둔다.

### 구현 (M4, 2026-09-27)
- 카드는 **정답 글자만** 준다(방해 카드 없음). 처음부터 정답 순서로 놓이지 않게 섞는다.
- 카드를 탭하면 첫 빈칸에 들어가고, 채운 칸을 탭하면 카드가 돌아온다. 힌트 칸은 되돌릴 수 없다.
- 8글자 이상이면 첫 글자를 힌트로 채워 둔다(`CardPuzzle.HINT_MIN_LETTERS`).
- 모든 칸이 차면 자동으로 채점한다.
  - 정답이면 초록색으로 "정답! 🎉"을 보여 주고 1.2초 뒤 다음 단어로 넘어간다.
  - 첫 오답이면 빨간색으로 "아쉬워요! 한 번 더 해 볼까요? 🙂"을 보여 주고, 1.5초 뒤 카드를 되돌려 **한 번 더** 도전하게 한다.
  - 두 번째 오답이면 "정답은 …"과 다음 버튼을 보여 준다.
- **첫 시도에 맞힌 경우만 정답으로 센다.** 기록(`StudyMode.CARD`)도 첫 시도 결과로 한 번만 남긴다. 결과 화면의 틀린 단어 목록에는 첫 번째로 틀린 답을 보여 준다.
- 레벨 2 기록은 "틀린 단어" 모음과 레슨 ⭐ 진행률에 **반영하지 않는다.** 둘 다 레벨 3 기준이다.
- 코드: `domain/CardPuzzle.kt`(단위 테스트 9개), `ui/study/CardViewModel.kt`, `CardScreen.kt`. 결과 화면은 레벨 3과 같은 `ResultView`를 쓴다.
- 실기기 확인(갤럭시 탭 S7+): 오답 → 재도전, 칸 탭으로 되돌리기, 정답, 두 번 오답 → 정답 공개, take off 띄어쓰기 칸, 결과 화면(첫 오답 표시). 테스트 기록은 삭제했다.

## 레벨 3 — 쓰기 (최우선)
사용자 결정: 철자는 **아이가 키보드로 직접 입력**한다. ([ADR 0003](../decisions/0003-keyboard-spelling-input.md))
- 발음 재생 → 입력 → 확인 버튼으로 채점 → 오답이면 정답을 보여주고 다음 단어로 (출처: raw/요구사항설계초안.txt)
- 키보드: **안드로이드 기본 키보드**를 쓴다 ([ADR 0004](../decisions/0004-system-keyboard.md)). 자동완성·자동수정·추천 단어는 반드시 꺼야 한다. 그렇지 않으면 키보드가 정답을 대신 알려준다. 한/영 전환 안내도 필요하다. 구현 체크리스트는 ADR 0004에 있다.
- 채점: 대소문자 무시, 앞뒤 공백 무시, 연속 공백은 하나로 본다(`take off`, `movie star`).
- 띄어쓰기 단어에는 "(2단어 · 띄어쓰기)" 힌트를 보여준다. 첫 태블릿 테스트에서 `take off`를 `takeoff`로 입력한 일이 있었다.
- **대회 연습**(M5, 구현됨) → [대회 연습](#대회-연습-m5)

## 공통
다시 듣기, 진행률(5/20), 정답률 집계 (출처: raw/요구사항설계초안.txt)
- 피드백(M5): 정답이면 올라가는 두 음 "딩동"과 튀어나오는 "정답! 🎉", 오답이면 낮은 소리와 입력칸·카드 칸 흔들림, 결과 화면의 별도 튀어나온다. 소리는 음원 파일 없이 앱이 합성한다(`tts/SoundEffects.kt`, `ui/Effects.kt`).

## 대회 연습 (M5)
사용자 요청(2026-09-27)으로 구현. 스펠링 비 대회(10월 중순)처럼 **뜻 없이 발음만 듣고 쓰는** 연습이다.
- 홈 레슨 목록 맨 앞의 **🏆 대회 연습** 카드 → 문제 수 선택(**10문제 · 20문제 · 전체**, 전체 문제 수는 고유 단어 수에 따라 자동으로 바뀜 — 2026-09-27 기준 96문제) → 레벨 3 쓰기 화면(제목 "🏆 대회 연습")
- 출제: 현재 레슨들의 **고유 단어**(2026-09-27 기준 96개)를 섞어 선택한 수만큼 무작위로 낸다. "처음부터 다시"를 누르면 새로 뽑는다. 가상 레슨 id `-2`(`CONTEST_LESSON_ID`).
- 뜻은 숨긴다. **"💡 뜻 보기"** 버튼을 누르거나 채점이 끝나면 뜻이 나온다. wind/right처럼 소리만으로 헷갈리는 단어 때문에 두었다. 실제 대회에서 뜻을 물어볼 수 있는 것과 같다.
- 기록은 레벨 3과 같은 `TYPE`로 남긴다 → 레슨 ⭐ 진행률과 틀린 단어 모음에 반영된다.
- 실기기 확인(2026-09-27): 카드와 시작 화면, 뜻 숨김과 뜻 보기, 여러 레슨에서 출제(groceries), 정답 뒤 다음 문제에서 뜻이 다시 숨겨짐. 테스트 기록은 삭제했다.
- 추후: 아직 못 맞힌 단어를 먼저 내기, 틀리면 바로 끝나는 실전 방식

## 틀린 단어 모음 (오답 다시 테스트)
사용자 요청(2026-09-26): 틀린 단어를 모아 다시 테스트하는 기능을 **레슨 쪽에** 추가한다.
- 레슨 선택 화면 맨 앞에 **"🔁 틀린 단어 · 다시 도전! N개"** 카드가 나온다. 틀린 단어가 없으면 카드가 숨겨진다.
- 모으는 기준: 현재 레슨들에 있는 단어 중 **레벨 3(쓰기)의 마지막 시도가 오답**인 단어. 모든 레슨에서 모은다.
- 다시 맞히면 마지막 시도가 정답이 되어 목록에서 빠진다. 그래서 이 목록은 "지금 고쳐야 할 단어"이고, 틀렸던 기록 전체가 아니다.
- 카드를 누르면 일반 레슨처럼 **레벨 선택 → 레벨 1 듣기 / 레벨 3 쓰기**로 공부한다.
- 레벨 1 듣기와 레벨 2 카드에서 틀린 것은 모으지 않는다. 듣기에는 채점이 없고, 카드는 아직 만들지 않았다.
- 구현: 가상 레슨 id `-1` (`WRONG_WORDS_LESSON_ID`), `WordDao.wrongWords()`.
- ✅ 실사용 확인(2026-09-27): 사용자가 카드가 잘 보인다고 확인. DB 기준 레슨 4에서 feel, hard, shine, take off 4개가 모였다. hard는 전날 맞혔지만 오늘 틀려서 들어갔다(마지막 시도 기준).
- 한 판 안의 "틀린 단어 다시 하기"(결과 화면 버튼)와는 별개다. 그 버튼은 방금 푼 판의 오답만 다시 푼다.
